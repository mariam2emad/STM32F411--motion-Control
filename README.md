# STM32F411 Motion Control PCB

Custom motion-control PCB designed around the STM32F411 microcontroller.

## Overview

This project is a custom PCB designed for a motion-control system.
The board is based on the STM32F411 MCU and provides interfaces for
motor control and encoder feedback.

## Hardware

- STM32F411 MCU
- Motor control interfaces
- Encoder interfaces
- Power regulation
- Communication interfaces

## My Contribution

I was responsible for the hardware design of this board, including:

- Schematic design
- Component selection
- PCB layout
- Component placement and routing
- Design verification
